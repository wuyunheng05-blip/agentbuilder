# AgentBuilder

一个面向开发者的 **AI Agent 运行时框架**，提供从智能体声明式构建、ReAct 推理执行、工具调用、多智能体协作到全链路可观测的完整能力。

## 技术栈

- Java 8 · Project Reactor · OkHttp · Jackson · Redis/Jedis
- OpenTelemetry · SLF4J + Logback
- JUnit 5 · Mockito · jqwik

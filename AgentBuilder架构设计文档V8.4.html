项目概览 01

AgentBuilder 是一个面向开发者的 AI Agent 运行时框架，提供从智能体声明式构建、 ReAct 推理执行、工具调用、多智能体协作到全链路可观测的完整能力。 它不是传统 Web 应用，而是 LLM 驱动智能体的执行引擎。

架构设计原则 02
01SPI 优先

全局 Configuration 接口作为扩展入口，所有核心组件可通过 Java SPI 替换

02流式优先

所有执行结果以响应式事件流返回，支持实时消费和背压控制

03关注点分离

钩子（只读观察生命周期）与拦截器（可变换 I/O）严格职责区分

04渐进复杂度

LLM 自主判断任务复杂度，决定是否从单步推理升级为规划执行

05组合装配

Builder 收集配置、Assembler 装配组件，运行时不可变，避免深层继承

06可靠性兜底

Outbox 事件投递 + 快照断点 + 熔断/限流/重试三板斧

执行链路详解

步骤层次动作
1API调用 agent.run(input)，校验状态机为可执行状态
2运行时创建独立执行上下文：消息历史副本、Token 预算、递归深度
3运行时注入生命周期钩子，检查递归/配额守卫（不满足则快速失败）
4运行时输入预处理：敏感数据脱敏 → 记忆注入 → 上下文提供者链
5推理进入 ReAct 推理循环，阶段管线驱动 Phase 链
6推理思考阶段：构造 Prompt → 调用 LLM → 解析决策
7工具行动阶段：通过工具网关执行 LLM 决定的工具调用
8推理终止决策：最终答案 / 继续 / 无动作修正
9运行时后处理：产物总结、Self-Consistency、Token 记账、钩子通知
10API流式返回事件：RUN_START → THINKING → TOOL_CALL → CONTENT_DELTA → FINAL

推理引擎 05

ReAct 阶段管线

推理引擎采用编排器驱动 Phase 链的模式，每轮迭代按顺序执行各阶段， 每个阶段返回控制流指令（继续 / 终止 / 异步边界 / 重试 / 下一轮）。

预检Token · 时间 · 深度
思考Prompt → LLM
行动工具网关执行
终止决策答案/继续/修正
反思步骤质量评估

控制流模型

while (iteration <= maxIterations) {
    for (Phase phase : phases) {
        PhaseResult result = phase.execute(context, sink);
        switch (result.action) {
            CONTINUE        → 执行下一个 Phase
            TERMINATE       → 完成流，退出
            ASYNC_BOUNDARY  → Phase 自管回调，退出同步循环
            RETRY_ITERATION → 从头重试本轮
            NEXT_ITERATION  → 进入下一轮
        }
    }
}

关键机制

异步边界恢复思考/行动阶段为异步执行，在回调中恢复管线推进
终止决策工具调用→继续迭代 / 最终答案→终止 / 无动作→注入修正重试
自一致性验证低置信度答案触发多次 LLM 采样，多数投票确认可靠性
迭代轨迹记录每轮记录：决策类型、工具列表、耗时、Token、是否模式升级

多智能体协作 08

四种协作模式

子智能体 (SubAgent)封装为工具注册到编排者，由编排者 LLM 自主决定何时调用。每个子智能体拥有独立上下文和记忆，支持多轮对话协议（NEEDS_CLARIFICATION）。
远程智能体 (RemoteAgent)通过 A2A（Agent-to-Agent）协议 HTTP 通信，支持自定义认证和连接池，实现跨服务边界的智能体调用。
工作流编排 (Workflow)用户预定义的有向无环图（DAG）流程，支持顺序、并行、条件分支、循环执行，节点可暂停等待人工审批。
自主规划执行 (PlanAndExecute)内置规划工具，LLM 判断任务复杂度后自行决定升级。任务分解 → 分配给 Worker 并行/串行执行。

关键机制

递归深度控制通过递归上下文管理嵌套调用深度（默认 max=2），到达上限快速失败
事件实时转发子执行单元的中间事件通过线程安全的 sink 实时转发到父级流
取消传播父级取消控制器注入到子智能体上下文，支持级联取消
共享/独立模型子智能体可选择共享父级模型或配置独立模型

治理与安全 09

认证授权

  • 身份认证服务 — 验证调用者身份
  • 权限校验服务 — 检查操作授权
  • 通过拦截器链自动生效

配额管理

  • 请求频率限制 — 防止滥用
  • Token 用量配额 — 控制成本
  • 超限快速失败，返回明确错误

敏感数据保护

  • 正则匹配：手机号、邮箱、身份证、银行卡、API Key
  • 输入预处理阶段自动脱敏
  • 可通过 SPI 自定义脱敏策略

韧性机制

  • 熔断器 — 模型调用连续失败时自动熔断
  • 限流器 — 控制并发请求速率
  • 自动重试 — 可配置重试策略
  • 超时控制 — wall-clock 超时兜底

代码沙箱隔离

  • bwrap namespace 隔离（需 CAP_SYS_ADMIN）
  • 多租户目录隔离：按 tenantId/accountId 分区
  • Skill 目录只读挂载
  • 产物检测 → 通知上层 → 持久化

Human-in-the-Loop

  • 高风险工具自动触发审批
  • 自定义 HITL 处理器（如控制台交互）
  • 暂停/恢复执行流程

可观测性 11

OpenTelemetry 三大信号

  • Traces — 每次 run 生成完整 Span 树，支持分布式追踪
  • Metrics — Token 用量、延迟分布、工具调用频率等指标
  • OTLP Export — 标准协议导出到 Jaeger / Prometheus

运行轨迹存储

  • Run 级追踪：时长、Token、状态、策略、模型名
  • Step 级追踪：每迭代的输入/思考/输出/耗时
  • 支持只读查询接口（审计/回放）

扩展机制 12

四大扩展点

① SPI Configuration（全局替换）最高级别扩展点。通过 Java SPI 替换全局配置中的任何默认实现：模型提供者、存储模块、记忆模块、配额服务、认证服务等。
② 拦截器（参与者，可变换 I/O）覆盖四个 I/O 边界：Run 前后 / LLM 调用前后 / 工具调用前后。支持短路能力（缓存命中/安全拒绝/限流）。
③ 生命周期钩子（旁观者，只读）观察 Run 生命周期事件：开始/步骤/完成/错误/清理。内置：快照钩子、可观测钩子、记忆钩子。
④ 上下文提供者（动态注入）每次调用前注入上下文（记忆、知识、动态指令），调用后提取状态存储。与拦截器职责互补。

自进化系统

框架内置智能体自我优化能力：

经验收集以钩子形式采集每次执行的经验数据
经验分析识别成功/失败模式，提取优化策略
策略优化根据性能指标自动调整执行参数
技能进化从经验中自动生成新工具定义和速查表

BOS Agent Builder

企业级 AI Agent 框架 — 整体架构视图

分层架构

🎯 公开接口层 (Public API Layer)
面向业务消费者的极简入口。提供 Agent 构建、执行、会话续接、断点恢复等核心能力，屏蔽内部复杂性。支持流式事件回调模式，消费者只需关注业务事件。
面向消费者
🔀 编排层 (Orchestration Layer)
请求入口与流程编排。负责拦截器链调度（短路/变换）、上下文提供者注入、生命周期钩子分发。将横切关注点与核心推理逻辑解耦。
流程控制
🧠 推理层 (Reasoning Layer)
ReAct 推理循环引擎。通过可插拔的阶段管线（感知→思考→行动→反思）驱动 LLM 自主推理，支持异步边界、迭代重试、收敛判断、自一致性验证。
核心引擎
⚡ 能力层 (Capability Layer)
Agent 的外部能力集合。统一工具网关、技能注册与发现、知识检索(RAG)、工作流编排(DAG)、多 Agent 协作、MCP 协议集成。LLM 通过 Function Calling 自主调度。
能力扩展
🤖 模型层 (Model Layer)
大语言模型调用抽象。统一流式/非流式接口，支持模型降级链、自动重试、限流保护、多模型切换。透明装饰器模式实现弹性增强。
LLM 抽象
💾 记忆与上下文层 (Memory & Context Layer)
上下文窗口与记忆管理。Token 预算分配、自动压缩守卫、记忆整合、工作记忆存储、会话历史维护。确保有限窗口内信息利用最大化。
状态管理
🛡️ 治理层 (Governance Layer)
企业级安全与合规治理。认证授权、输入/输出护栏、Token 配额管控、熔断器、限流器。保障 Agent 在生产环境安全可控运行。
安全合规
🏗️ 基础设施层 (Infrastructure Layer)
底层技术支撑。多后端持久化（内存/文件/Redis/JDBC）、事件总线、可观测性（OpenTelemetry 分布式追踪与指标）、快照存储、远程 Agent 通信(A2A)。
技术底座

核心模块与组件职责

🏗️
Agent 构建器
通过流式 Builder 模式构建 Agent 实例。支持代码构建、YAML/JSON 声明式配置、工厂模式创建。统一配置模型、工具、技能、知识、子Agent、工作流等所有能力。
流式构建 声明式配置 YAML/JSON
🧠
推理引擎
基于 ReAct（Reasoning + Acting）模式的推理循环。阶段管线架构：预检查→思考(LLM)→行动(工具)→反思。支持异步边界、迭代控制、收敛判断、自一致性验证。
ReAct循环 Phase Pipeline 异步边界 收敛控制
🔧
工具系统
统一工具网关，管理工具注册/发现/调用全生命周期。支持内置工具、自定义工具、MCP 协议工具。完整调用链路：参数校验→权限检查→人工审批(HITL)→执行→重试→审计。
统一网关 MCP协议 HITL审批 权限控制
🤖
模型抽象
大语言模型统一调用层。流式/非流式统一接口，支持 Thinking Token 输出。装饰器模式实现弹性增强：自动重试、模型降级链、速率限制、拦截器注入。
流式响应 降级链 自动重试 Thinking
🔗
多 Agent 协作
支持三种协作模式：本地子Agent（独立上下文、支持多轮追问）、工作流编排（确定性DAG流程）、远程Agent（A2A协议跨服务通信）。编排者Agent通过LLM自主决策调度。
子Agent 工作流DAG 远程A2A 自主调度
📋
工作流引擎
DAG 图引擎驱动的确定性流程编排。支持顺序、并行、条件分支、循环等模式。节点类型包括 Agent 节点、工具节点、条件节点。工作流作为工具暴露给编排者Agent。
DAG编排 条件分支 并行执行 循环
💾
记忆管理
多层记忆体系：Token 预算精细分配（System/Tool/History）、自动压缩守卫（阈值触发增量压缩）、工作记忆存储（短期+长期）、记忆整合（跨轮次信息聚合）。
Token预算 自动压缩 记忆整合 淘汰策略
📚
知识检索 (RAG)
知识库作为工具能力注册，LLM 自主决定何时检索。支持单知识库独立工具和多知识库自动聚合路由。文档分块、向量检索、混合搜索模式。
自主检索 多知识库 自动路由
🎯
技能系统
渐进式技能加载模型：发现→激活→执行。技能绑定工具集合，按需加载减少上下文占用。支持技能注册表、能力描述、动态发现。
渐进加载 按需激活 工具绑定
🔀
拦截器链
覆盖四个 I/O 边界的中间件体系：主流程层、推理层(LLM调用)、工具层。支持短路能力（缓存命中/安全拦截/限流熔断），按优先级排序执行。参与者角色，可变换输入输出。
短路能力 I/O变换 优先级排序 四层覆盖
👁️
生命周期钩子
推理运行的观察者机制。在关键生命周期节点回调：启动、每步、完成、错误、结束。只读观察不修改流程，用于日志、追踪、快照、审计等横切关注点。
观察者模式 生命周期 不侵入
🛡️
治理与安全
企业级治理能力集合：认证授权（Agent/工具级权限）、输入输出护栏（安全过滤）、Token 配额管控、熔断器（失败计数+半开探测）、限流器（滑动窗口+令牌桶）。
认证授权 护栏规则 配额管控 熔断限流
📊
可观测性
基于 OpenTelemetry 的全链路可观测。分布式追踪（Span/Trace）、指标采集（Token用量/延迟/成功率）、结构化日志。覆盖 Run/Step/Tool/LLM 四个粒度。
OpenTelemetry 分布式追踪 指标采集 OTLP导出
💿
持久化存储
多后端统一存储抽象。支持内存（开发测试）、文件（单机）、Redis（分布式快照/事件）、JDBC（生产审计）。版本化接口支持缓存快速失效。
多后端 Redis JDBC 版本化
📸
快照与恢复
执行状态的捕获与恢复。两种模式：会话续接（跨请求多轮对话，通过 sessionId 恢复历史）、断点恢复（故障恢复，从快照继续中断的推理）。
会话续接 断点恢复 状态捕获
📡
事件总线
发布/订阅模式的事件系统。支持执行事件的异步分发、可靠投递保证。解耦组件间通信，支持外部系统集成通知。
发布订阅 可靠投递 异步分发
🌐
远程托管 (A2A)
Agent 间跨服务通信协议。支持远程 Agent 端点注册、HTTP 通信、自定义客户端（认证/重试/连接池）。实现分布式多 Agent 系统的互联互通。
A2A协议 HTTP通信 自定义Client
🧬
自我进化
Agent 自我改进能力。经验分析与提取、Cheatsheet 管理（最佳实践积累）、技能演化（从执行经验中学习新技能）。持续提升 Agent 推理质量。
经验提取 Cheatsheet 技能演化
✍️
提示词工程
模板化提示词管理。支持变量占位符渲染、资源文件加载、动态变量提供者注入。分离提示词定义与运行时变量，支持多环境配置。
模板渲染 变量注入 资源加载
⚙️
配置与扩展
SPI 机制驱动的扩展点体系。支持自定义模型提供者、存储后端、知识检索器、脚本引擎等。插件化架构，框架核心与扩展实现解耦。
SPI扩展 插件化 多引擎

架构设计原则

全链路响应式流
从用户输入到最终输出，全程基于 Reactive Streams（Flux）。支持逐 Token 推送、中间步骤实时可观测、背压控制。消费者通过事件回调获取结果，无需阻塞等待。
可插拔阶段管线
推理循环拆分为无状态的 Phase 策略对象，通过编排器驱动。支持异步边界（LLM流式/工具异步）、迭代重试、收敛终止。新增推理阶段只需实现 Phase 接口。
参与者/观察者分离
横切关注点分为两类：拦截器（参与者，可变换 I/O、可短路）和钩子（观察者，只读观察不修改流程）。职责清晰，避免观测逻辑意外影响推理结果。
LLM 自主决策
工具调用、子Agent调度、工作流触发、知识检索均由 LLM 通过 Function Calling 自主决定。框架不硬编码调用逻辑，最大化 LLM 的推理自由度。
治理内建
安全、合规、弹性作为框架一等公民。认证授权、护栏规则、配额管控、熔断限流不是事后补丁，而是架构级设计，确保生产环境安全可控。
多后端可替换
存储、模型、知识检索等基础设施通过接口抽象，支持多后端无缝切换。开发用内存、测试用文件、生产用 Redis/JDBC，无需修改业务代码。
